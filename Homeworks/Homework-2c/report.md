For example, one use was a professor using RAG to train an LLM to aid him with teaching his class. It helped with class preparation and students could interact with it. That could only be done by using RAG as the information on the class is very specific that an AI chatbot might not be able to teach the concepts with the same efficicency. 

Another example would be for video summaries. The LLM would get information from the database and not from the LLM trying to figure out what the video was about through clues like titile and description, which elevates the accuracy of the responses. 

Lastly, they integrated a RAG with other models to guardrail and judge the response, which demostrates how RAGS can be impleemnted in a more complex architecture to ensure accurate and meaningful responses.
