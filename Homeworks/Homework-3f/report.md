 # Report Homework 3f

 For this homework assigment I chose to do something with crewai as I thought it was going to be the one that I can easily use in a simple project.

 It was really easy to use to be honest. All I had to do was follow the documentation and just change a few things. I ended up doing something really silly. First, I created an agent that managed a magical store and had to create an inventory of magical items.

 Then, I created an agent that would create a marketing strategy for that magical shop. It was really interesting how I didn't explicitely told it to use the elements of the magic shop but it did and it was really interesting.

 I can totally see the value of agent frameworks since it was really easy to make this. I just had to edit a few edits to just a couple of files and I was able to get the whole program started.

 Although, I do wonder what is the difference between an agentic framework and a harness.

 But yeah, this was really fun to do and can see myself maybe using it in the future.
